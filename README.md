# Azure 3-Tier Java Application Deployment

## Project Overview
Deploy a Java application using a highly available
3-tier architecture on Microsoft Azure.

## Architecture
- Presentation Tier: Nginx
- Application Tier: Apache Tomcat
- Data Tier: Azure Database for MySQL

## Infrastructure
- Azure Virtual Network
- Public and private subnets
- Azure VM Scale Sets
- Azure Load Balancer
- Application Gateway
- Azure Database for MySQL
- Azure Managed Redis
- Azure Key Vault
- Azure Monitor
